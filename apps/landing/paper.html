Abstract

As autonomous AI agents are entrusted with mission-critical multi-step enterprise workflows (e.g. database transactions, cloud provisioning, payment dispatch), runtime failures caused by external API timeouts, rate-limits, and model hallucinations are inevitable. Current industry practices exhibit two catastrophic extremes: (1) Blind Full-Restarts, which incur severe token costs and risk duplicate external side-effects, and (2) Naive Snapshot Restores, which suffer from semantic rollback vulnerabilities as classified in recent ACRFence research (arXiv:2604.28138). In this paper, we present AEONRIFT, an enterprise-grade time-travel and durable execution infrastructure. AEONRIFT combines an append-only SHA-256 Causal State Directed Acyclic Graph (DAG), an Idempotency Rollback Guard, a 6-Tier Semantic Checkpoint Hierarchy (L0–L5) that eliminates over 75% of redundant turn snapshots, and a native Model Context Protocol (MCP) server with an in-memory sliding window ring buffer sustaining 50,000 events/second. Evaluation on the RIFT-Bench testbed demonstrates a 94.2% autonomous recovery rate with zero duplicate side-effect hazards and only 14ms normalized recovery latency.

1. Introduction & The Reliability Crisis § 1.0

Unlike deterministic microservice architectures, autonomous agent workflows are governed by non-deterministic probabilistic models (LLMs) executing asynchronous external tool calls. When a failure occurs at Step 48 of a 50-step execution trajectory:

  • Cost Explosion: Re-executing all 48 previous steps re-incurs substantial LLM inference token billing and excessive network latency.
  • Side-Effect Duplication: Re-running code that previously called external state-mutating APIs (e.g., Stripe charges, AWS EC2 spin-ups, customer email notifications) leads to financial and operational desynchronization.
  • Semantic Inconsistency: Restoring memory variables without reconciling external state leads to dangling pointers and invalidated auth tokens.

2. Causal State DAG & Cryptographic Lineage § 2.0

AEONRIFT models every agent interaction as an immutable node in a Causal State Graph. Each event \(e_i\) cryptographically seals the execution prefix by chaining the SHA-256 hash of its predecessor:

H(e_i) = \text{SHA256}\Big(\text{id} \parallel \text{parent\_hash} \parallel \text{step} \parallel \text{H}(\text{payload}) \parallel \text{timestamp}\Big)

This mathematical property guarantees that execution lineage cannot be tampered with or desynchronized during asynchronous branch recovery.

3. The ACRFence Rollback Guard § 3.0

In recent 2026 security research on Agent Checkpoint Rollback (ACRFence, arXiv:2604.28138), researchers proved that naive checkpoint rollbacks expose applications to severe security vulnerabilities. If an agent commits a financial transaction at Step 12, crashes at Step 15, and is simply rewound to Step 10, the agent may attempt to charge the credit card a second time.

AEONRIFT Theorem 1 (ACRFence Immunity):
No action \(a \in \mathcal{A}_{\text{mutating}}\) with idempotency key \(k_a\) present in the committed side-effect ledger \(\mathcal{L}\) shall be permitted to re-execute during verified-prefix replay without explicit compensation.

AEONRIFT intercepts tool calls and categorizes their side-effect types:

Side Effect Class Reversibility Rollback Replay Policy
READ_ONLY REVERSIBLE Immediate transparent replay allowed.
MUTATING_REVERSIBLE COMPENSABLE Compensation action dispatched prior to step execution.
MUTATING_IRREVERSIBLE IRREVERSIBLE BLOCKED by Rollback Guard; output injected from ledger.
