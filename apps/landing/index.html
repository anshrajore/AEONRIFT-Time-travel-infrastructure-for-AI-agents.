"Naive checkpoint restore creates semantic rollback attacks. Naive retries duplicate side-effects. AEONRIFT brings causal time-travel durability to AI agent runtimes."

AEONRIFT is not another retry library. It is grounded in three landmark 2026 research papers (Crab, RePoT, ACRFence) that revealed the fundamental unsafety of existing agent recovery approaches. Every design decision — from the causal state DAG to the 6-level checkpoint hierarchy — is traceable to a specific research finding.

SECTION 02

How It Works

Six-step process
01
⚡
Intercept

AeonriftRuntime wraps every tool call, evaluating rollback hazards and semantic checkpoint policies before execution proceeds.

02
🌐
Emit to DAG

Each event is SHA-256 causal-hashed into an append-only DAG. Side effects are registered in the idempotency ledger with unique keys.

03
💾
Checkpoint

Layered snapshots L0–L5 are created at semantically significant moments. HMAC-signed and secret-scrubbed before persistence.

04
🔥
Detect Failure

FailureClassifier pattern-matches failures: TOOL_FAILURE, NETWORK, AUTH, STATE_CORRUPTION, LLM_FAILURE — each mapped to a recovery strategy.

05
🧠
Plan Recovery

RecoveryPlanner traverses the causal graph, checks ledger hazards, and selects REPLAY / REPAIR / REPLAN / COMPENSATE with a confidence score.

06
✅
Validate & Resume

RecoveryValidator verifies checkpoint integrity, reconciles environment drift, and resumes from the safest verified state without re-executing side-effects.

SECTION 03

Recovery Modes

Four strategies
MODE / 01
▶
Replay
REPLAY

Re-execute events from the last safe checkpoint with idempotency guarantees. Uses verified-prefix replay inspired by RePoT. Fastest path to resumption.

⚡ Fastest recovery
MODE / 02
▶
Repair
REPAIR

Surgically fix corrupted state nodes in the causal DAG without replaying the entire trajectory. Minimises re-computation cost and avoids unnecessary re-execution.

🔧 Minimal overhead
MODE / 03
▶
Replan
REPLAN

When the original plan is unrecoverable, generate a new execution path from the current known-good environment state. Full strategic pivot, safe restart.

🔄 Strategy pivot
MODE / 04
▶
Comp.
COMPENSATE

For irreversible side effects that cannot be rolled back, issue compensating actions. Guards against ACRFence-class rollback attacks: duplicate payments, resurrected credentials.

🛡️ Safety critical

Key Design Decisions
1
Semantic checkpoint selection (Crab)
Snapshots are triggered by policy, not by N-turn intervals. >75% of turns produce no recovery-relevant state and are skipped.
2
Causal hashing (SHA-256 parent chain)
Every event hash includes the parent event hash, forming a cryptographically linked DAG — any tampering is immediately detectable.
3
Idempotency ledger (ACRFence guard)
Irreversible side effects are registered before execution. During replay the ledger blocks re-execution, preventing duplicate payments and ACRFence attacks.
4
ML predictive policy
RiftPredictPolicyModel scores recovery strategies from a RIFT-FAIL synthetic dataset. RiftCheckpointPredictor scores checkpoint importance 0.0–1.0.
5
Multi-agent fleet recovery
DistributedAgentCoordinator tracks inter-agent causal messages and cascades recovery across downstream agents automatically.
SECTION 05

Research Foundation

2026 arXiv
arXiv 2026 · Crab
Semantic-Aware Checkpointing

Crab introduces semantic checkpointing for agent sandboxes, showing that blind per-turn snapshots are wasteful and fail to capture recovery-relevant state transitions.

📊 >75% of turns produce no recovery-relevant state
arXiv 2026 · RePoT
Verified-Prefix Replay

RePoT demonstrates that safe recovery requires cryptographically verified prefix trajectories. Simple event log replay without hash verification leads to non-deterministic failures.

📊 Checkpoint repair eliminates false replays
arXiv:2604.28138 · ACRFence
Semantic Rollback Attacks

ACRFence reveals that naive checkpoint restore creates catastrophic security vulnerabilities: duplicate payment execution, resurrected invalidated credentials, and cross-session state desync.

🛡️ AEONRIFT ledger guards all ACRFence attack classes
