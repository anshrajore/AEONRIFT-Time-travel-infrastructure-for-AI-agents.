How It Works

Six steps from failure to recovery

AEONRIFT wraps your agent's tool calls, tracks every state mutation, and orchestrates intelligent recovery without duplicating side effects.

01
⚡
Intercept
AeonriftRuntime wraps every tool call, evaluating rollback hazards and semantic checkpoint policies before execution.
02
🌐
Emit
Each event is hashed into a causal state graph (DAG) with SHA-256 parent chains. Side effects are registered in the ledger.
03
💾
Checkpoint
Layered snapshots L0–L5 are created at semantically significant moments — not blindly every N turns (inspired by Crab).
04
🔥
Detect Failure
RiftChaosEngine or real failures trigger FailureClassifier — pattern-matched to TOOL_FAILURE, NETWORK, AUTH, STATE_CORRUPTION, LLM.
05
🧠
Plan Recovery
RecoveryPlanner traverses the causal graph, checks ledger hazards, and selects REPLAY / REPAIR / REPLAN / COMPENSATE with a confidence score.
06
✅
Validate & Resume
RecoveryValidator verifies checkpoint integrity (HMAC), reconciles environment drift, and resumes execution from the safest valid state.
Recovery Modes

Four strategies. One decision engine.

AEONRIFT never blindly retries. It classifies failures and selects the mathematically safest recovery path, verifying idempotency of every committed side effect.

▶
Mode 01
REPLAY
Re-execute events from the last safe checkpoint with idempotency guarantees. Uses verified-prefix replay (RePoT-inspired).
⚡ Fastest recovery
▶
Mode 02
REPAIR
Surgically fix corrupted state nodes in the DAG without replaying the entire trajectory. Minimizes re-computation cost.
🔧 Minimal overhead
▶
Mode 03
REPLAN
When the original plan is unrecoverable, generate a new execution path from the current known-good environment state.
🔄 Strategy pivot
▶
Mode 04
COMPENSATE
For irreversible side effects that cannot be rolled back, issue compensating actions. Guards against ACRFence-class rollback attacks.
🛡️ Safety critical

Research Foundation

Built on 2026 peer-reviewed findings

AEONRIFT is not another retry library. It is grounded in the three landmark 2026 papers that changed how we think about agent fault tolerance.

arXiv 2026 · Crab
Semantic-Aware Checkpointing
Crab introduces semantic checkpointing for agent sandboxes, showing that blind per-turn snapshots are wasteful and insufficient.
📊 >75% of turns produce no recovery-relevant state
arXiv 2026 · RePoT
Verified-Prefix Replay
RePoT demonstrates that safe recovery requires cryptographically verified prefix trajectories, not simple event log replay.
📊 Checkpoint repair eliminates false replays
arXiv:2604.28138 · ACRFence
Semantic Rollback Attacks
ACRFence reveals that naive checkpoint restore can create catastrophic vulnerabilities: duplicate payments, resurrected credentials, and state desync.
🛡️ AEONRIFT's ledger prevents all ACRFence attack classes
Developer Experience

One install. Eight commands.

Install via pip or npm. Use the same CLI whether you're building in Python or TypeScript.

aeonrift CLI — zsh
# Install AEONRIFT
$ pip install aeonrift-core aeonrift-runtime aeonrift-cli
# or via npm
$ npm install -g aeonrift

# Initialize a new project
$ aeonrift init my-agent
✓ Initialized AEONRIFT project in ./my-agent

# Inspect agent timeline
$ aeonrift timeline exec-abc-123
[T+0.000] tool_call payment_api IRREVERSIBLE
[T+0.210] checkpoint L3-snapshot ✓ HMAC-OK
[T+1.430] failure PROCESS_KILL severity=CRITICAL
[T+1.431] recovery REPLAY confidence=0.94

# Run chaos experiment
$ aeonrift chaos --type NETWORK_LOSS --duration 5
✓ Chaos experiment complete · recovery_rate=94.2%

# Diagnose your environment
$ aeonrift doctor
✓ Python 3.11+ · ✓ storage writable · ✓ HMAC key set
$
Full Feature Set

Everything you need for production-grade agent fault tolerance

🌐
Causal State Graph (DAG)
SHA-256 causal hashing chains every execution event into a tamper-evident DAG. Find the last safe checkpoint in O(n) time.
💳
Side Effect Ledger
Track every irreversible action (payments, emails, API writes) with idempotency keys. Prevents duplicate execution during replay.
🔮
ML Predictive Policy
RiftPredictPolicyModel and RiftCheckpointPredictor use rule-guided ML to select recovery strategies and optimal checkpoint moments.
🛡️
HMAC-SHA256 Security
CheckpointSecurityGuard signs all snapshots and scrubs secrets before storage. Detects any checkpoint tampering before restoration.
🤝
Multi-Agent Fleet Coordinator
DistributedAgentCoordinator tracks inter-agent causal messages and orchestrates cascading recovery across agent fleets.
